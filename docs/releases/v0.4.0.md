Adds named egress profiles and fixes routing after Caido restarts.

- Configure authenticated HTTP CONNECT or SOCKS5h proxies through `set-egress` and `get-egress`. Names are independent of request colors; destination DNS is resolved by the proxy.
- Select a route with `X-Morpheus-Egress`. Caido retains the selector for Replay; the transport strips it before forwarding. Each name has isolated connections and TLS session caches.
- Persist credentials owner-only. Reads return redacted endpoints, and proxy failures use sanitized errors without direct fallback.
- Rebind enabled upstream rules at startup to work around Caido 0.59.0's ordering issue, preserving filters and rank.
- Return HTTP 503 through a native rejection responder when forwarding is stopped or disabled, avoiding Caido's fallback after hook exceptions.

Existing saved TLS selections and upload limits are preserved. Requests without an egress selector keep their existing direct egress behavior. Per-egress TLS overrides are not enabled in this release. Linux x86_64 only.

Validated in Docker with Go and race tests, 31 backend tests, type checking, lint, unused-code and package checks, eight pinned Chrome/relay comparisons, and persistent Caido 0.59.0 tests covering HTTP, WebSockets, Replay, Automate, remote DNS, redaction, restart persistence, and failure without direct fallback.

Install `plugin_package.zip` through Caido's plugin installer. `plugin_package.zip.sha256` contains its SHA-256 checksum. See the [egress guide](https://github.com/ahmetdotrun/caido-impersonate-tls/blob/v0.4.0/docs/egress.md) for configuration.
